# Hyper-Tenant Secure Payment Portal

A Flutter test task for a configuration-driven, multi-tenant payment
confirmation module with Android security integration.

## Setup

Install FVM, then use the Flutter version declared in `.fvmrc`:

```sh
fvm install
fvm flutter pub get
fvm flutter run
```

Run project checks with:

```sh
fvm flutter analyze
fvm flutter test
```

Implementation progress is tracked in [`plan.md`](plan.md).
